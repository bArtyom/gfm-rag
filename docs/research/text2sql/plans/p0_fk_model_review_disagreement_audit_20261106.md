# P0 双模型 FK 审阅分歧归因审计

**状态：运行前登记；只读、CPU-only 结果归因，不新增标签或方法效果结果。** 本次只分析已经完成的 60 单元双模型审阅，判断分歧是否与候选数量、候选展示顺序、决定类别或自报理由有关。

## 研究问题与边界

- **问题：** 既有双模型审阅的 29 个不一致单元，是否集中在三候选单元、候选顺序不同的单元或特定决定/理由组合？这些因素可以指出审阅代理的失效模式，但不能判定哪个模型的语义判断正确。
- **层级：** exploratory error attribution；不属于新模型实验、标注实验、主实验、消融或独立复现。
- **分析单位：** 已冻结的 60 个问题×表对审阅单元；不抽样、不追加问题。
- **预设描述项：** 两模型有效率；精确决定+接受集合一致率；决定不一致与“决定相同但集合不同”的计数；按候选数（2/3）和 A/B 候选显示顺序（相同/不同）分组的一致计数；决定、理由码、置信度分布；按模型自身包中候选位置统计 single/multiple 选择是否包含首位候选。
- **判定方式：** 仅报告匿名计数和比例，不做显著性检验、不作因果解释、不把自报理由当作真实错误类型。若分组差异很小或方向相反，结论为“本审计未发现清晰的结构集中模式”。
- **完整性门：** 必须覆盖 60 个冻结单元；复算有效输出数 `59/58`、双有效 `57`、精确一致 `28`、候选直方图 `2:45 / 3:15`、A/B 候选顺序不同 `31`，并逐一匹配冻结输入哈希。任一不符则停止，不发布聚合。
- **停止条件：** 一次分析完成即停止；不重跑模型、不改 prompt、不扩样、不做 G-reasoner 排序，也不尝试用模型共识替代人工可信标签。
